# Homebrew tap

Casks for apps by [aleibovici](https://github.com/aleibovici).

```bash
brew install --cask aleibovici/tap/grammarfix
```

| Cask | Description |
| --- | --- |
| `grammarfix` | [GrammarFix](https://github.com/aleibovici/grammarfix), a macOS menu bar app that fixes the grammar of selected text |
